# CFRP RVE 自動生成（Abaqus/CAE 2016）

## 何ができるか

- 炭素繊維径 **7 µm（固定）**、樹脂 PEEK、2D 断面を設定する。
- `VFS = (0.00, 0.30, 0.40, 0.50, 0.60)` を変更し、繊維体積含有率を指定する。
- `GRID_SIDE = 4` の場合、繊維16本を有限サイズの正方形セルに配置。格子初期状態からランダム移動で非重複の配置を生成する。**完全ランダムな統計分布を保証するものではない**。
- `RANDOM_SEEDS = (11, 21, 31)` のように複数の配置で比較可能。
- 2D「樹脂のみ」形状（不透過繊維は円形穴）、DC2D3三角形メッシュ、Steady-state Mass Diffusion、上下の濃度境界条件、RFL出力、Job、`.cae`、`.inp`、`.svg`を生成。
- 計算後、別スクリプトでRFL反力の合計から `P_eff/P_m`、`D_eff/D_m` を出力。

## 1. 実行方法

1. `cfrp_rve_abaqus2016.py` をAbaqusが動くWindows PCに保存する。
2. Pythonファイル冒頭の **USER SETTINGS** で変更する。初回は `VFS=(0.00,0.30,0.40)`、`RANDOM_SEEDS=(11,)` が安全。
3. Abaqus/CAE 2016の **File → Run Script** で実行する。コマンドラインなら `abaqus cae noGUI=cfrp_rve_abaqus2016.py`。
4. 作成される `cfrp_rve_results` 内の `.cae` を開き、メッシュ、上下のBC、繊維境界にBCがないこと、節点数を確認する。`.svg` で繊維の配置を確認できる。
5. `RUN_JOBS=False` のため、初期設定では自動解析を行わない。Abaqus CAEのJobから実行するか、物理条件を検証した後に `RUN_JOBS=True` として再実行する。
6. 解析 `.odb` が出揃ったら `cfrp_rve_postprocess.py` の `OUTPUT_DIR` を `.odb` と `rve_geometry.json` のフォルダに合わせ、`abaqus python cfrp_rve_postprocess.py` を実行する。
7. `rve_effective_properties.csv` で各 `V_f` と有効物性を比較する。

## 2. 物性値・単位

最初の入力例は再実験後のPEEK 2 mm樹脂を仮定：

| 項目 | スクリプト値 | 内容 |
|---|---:|---|
| `MATRIX_D_MM2_S` | `2.17e-4` | D = 2.17×10⁻¹⁰ m²/s |
| `MATRIX_SOL_KG_MM3` | `5.887e-13` | p_ref = 101325 Pa基準で換算した Abaqus Solubility |
| `NNC_TOP` | `106325/101325` | 上流純He 106325 Paと仮定 |
| `NNC_BOTTOM` | `0` | 下流真空 |
| `OUT_OF_PLANE_MM` | `1.0` | 2D面外厚さを1 mmに指定 |

## 3. 物理モデルに関する重要な制約

- **定常拡散専用の初版**。現在の出力は `P_eff` と、`S_eff=(1-Vf)S_m` を仮定して算出した均質化 `D_eff`。実験の非定常 `t50` から求める `D_app` と同義ではない。
- **繊維軸に垂直方向の拡散**を扱う。繊維が紙面奥行方向に伸びる一方向UD材を仮定する。織物CFRPや積層板全体を直接再現しない。
- **界面拡散・ボイド・き裂は未考慮**。円形穴の境界は無流束。
- **左右端は無流束（周期境界条件ではない）**。本格的な統計RVEとして発表する前に、周期境界条件の導入・RVEサイズ依存性確認が必要。
- 高Vfでは空隙が細くなる。粗いメッシュで流束が誤るため、粗細2種類以上のメッシュで収束確認する。
- **Abaqus 2016 Student Editionの通常の1000節点制限**に配慮し、最初のスクリプトでは950節点を超えるモデルを停止する。必要に応じてNを減らす、粗いメッシュにする、大学ライセンスを使う。
- 同じ実験から求めた樹脂物性を使う場合、良好な一致は完全な独立予測ではない。
- これは**動作をAbaqus実機で検証していない試作スクリプト**。出力したinpを含め、初回は必ず目視検証する。

## 4. 有効物性を求める式

下流の境界節点すべてについて符号付きの `RFL` を合計。流量絶対値 `|m_dot|` を求める。

`P_eff/P_m = |m_dot| / [s_m D_m DeltaNNC (Lx depth/Ly)]`

`S_eff/S_m = 1-Vf`（不透過・不溶解繊維かつ樹脂だけがHeを蓄積する仮定）

`D_eff/D_m = (P_eff/P_m)/(1-Vf)`

今回の正方形セルは `Lx = Ly` なので上記式の寸法項が相殺される。なお、境界RFLは**同一節点の重複合計をしない**。入口・出口のRFL総和が符号反対で同じ大きさになることも検証する。

## 5. 次の改良案

1. ランダム配置の品質を繊維径・最近接距離分布で定量確認。
2. 切断繊維を周期複製した真のPeriodic RVEと周期境界条件。
3. 非定常解析から均質な見かけの `t50` と `D_app` を算出。
4. 実試験片の断面像から繊維配置を抽出して代表性を確認。
